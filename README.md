# 食事写真記録

撮るだけで食事を記録し、週1回見返すための自分用PWA。

- 起動するとカメラが立ち上がる
- 撮影後に 朝食 / 昼食 / 夕食 / 間食 を1タップで選んで保存
- 写真は端末内（IndexedDB）にだけ保存し、カメラロールには残らない
- 見返し画面は日付ごとに4枠の写真が並ぶ

## 開発

```
npm install
npm run dev
```

## 公開

main へ push すると GitHub Actions が GitHub Pages へデプロイする。

## Googleドライブへのバックアップ（任意）

Google Apps Script のウェブアプリを自分のアカウントで公開し、アプリからそこへ写真を送る。
アプリ側に Google ログインは無い。

1. https://script.google.com で「新しいプロジェクト」を作る
2. エディタのコードを [gas/Code.gs](gas/Code.gs) の内容で置き換えて保存する
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
4. 「デプロイ」を押し、求められたら Google ドライブへのアクセスを承認する
5. 表示された「ウェブアプリのURL」をコピーする
6. アプリの「記録」→「バックアップ」でURLを貼り、「保存して接続を確認」を押す

以後、保存した写真は自動でマイドライブの「食事写真記録」フォルダへ送られる。
機種変更時は新しい端末で同じURLを入れて「ドライブから復元」を押す。

GAS のコードを変えたときは「デプロイ」→「デプロイを管理」→ 編集 → バージョン「新バージョン」で更新する（URLは変わらない）。
